# TRUSTFORGE

> An autonomous software factory that doesn't just build an application — it challenges, verifies, repairs and proves its critical behaviors.

TrustForge is a reusable software factory for trustworthy software and automation.

## Factory loop

ARCHITECT → OPERATOR → ADVERSARY → VERIFIER → REPAIRER → VERIFIER → EVIDENCE

The important output is not merely working code. It is a traceable claim about what was tested, what was observed, what failed, what was repaired and what was independently re-verified.

The final judged result additionally requires the complete Band room download as room.json.

## Trust states

- VERIFIED — independently verified within the declared scope.
- PARTIALLY_VERIFIED — evidence is incomplete.
- FAILED — a required property was demonstrated to fail.
- INCONCLUSIVE — evidence is insufficient for a verdict.
- BLOCKED — work could not proceed because a dependency or decision is unresolved.

## Design principle

TrustForge never treats implementation output as verification. A failed result is preserved, repaired deliberately, and returned to an independent Verifier.

See FACTORY.md for the complete factory contract.
